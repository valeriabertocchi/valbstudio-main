# Calendario

Calendario e task per iPad, in stile Calendario di Apple.

- Viste Giorno, 3 giorni, Settimana, Mese e Anno, con scorrimento fluido col dito
- Task con Oggi, giorno scelto, Da sistemare, liste e sottotask
- Calendari colorati collegabili alle schede
- Schede con paragrafi, riquadri e titoli a tendina
- Eventi che si ripetono, durata da trascinare, annulla e duplica

## Come aprirla

Apri `index.html` nel browser, oppure pubblicala con GitHub Pages
(Settings › Pages › Deploy from a branch › `main` / root).
Su iPad: Safari › Condividi › Aggiungi alla schermata Home.

I dati per ora restano nel browser del dispositivo (localStorage).
